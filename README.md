# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

kr1-html-css-shop/
├── index.html — главная страница
├── catalog.html — каталог товаров
├── product.html — карточка товара
├── order.html — страница оформления заявки
├── contacts.html — контакты
├── css/
│ └── style.css — общий файл стилей
├── js/
│ └── main.js — модальное окно и обработка формы
├── images/ — изображения
├── .gitignore
└── README.md

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3 (переменные, Flexbox, Grid, состояния)
- JavaScript (минимальный — модальное окно и валидация формы)
- Git
- GitHub
- GitHub Pages

## Что реализовано

- Многостраничная структура (5 страниц)
- Единая навигация на всех страницах
- Якорные ссылки на главной странице
- Хлебные крошки на внутренних страницах
- Карточки товаров с бейджами («Скидка», «Новинка»)
- CSS Grid для сетки товаров
- CSS Grid для страницы каталога (фильтры + товары)
- Flexbox для навигации и внутренней структуры карточек
- Модальное окно с формой заявки (`<dialog>`)
- Базовая HTML-валидация формы
- CSS-переменные в `:root`
- Состояния `:hover`, `:focus-visible`, `:disabled`
- БЭМ-именование классов
- Позиционирование (`sticky`, `absolute`, `fixed`)
- Публикация через GitHub Pages

## Как посмотреть проект

1. Открыть `index.html` в браузере.
2. Перейти по ссылке GitHub Pages (см. выше).
3. Для локального запуска с Live Server: правой кнопкой по `index.html` → **Open with Live Server**.
